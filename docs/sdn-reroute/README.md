# SDN rerouting research project (EE-353)

Planning documents for "Learning the Cost of Rerouting: disruption-aware
elephant-flow load balancing in an SDN controller". The experiments themselves
live in the `sdn-reroute` working folder on the lab laptop (Mininet needs root);
these files are the shared plan.

- `BRIEF.md`: the standing project brief (the `CLAUDE.md` used in the experiment folder).
- `CHUNKS.md`: the chunk-by-chunk plan. Section B is the active plan.
- `CHUNK0_REVIEW.md`: Chunk 0 technical review of the proposal and the reasons for the plan.
- `research_gap.md`: prior-work analysis the proposal rests on.

Copies of these files are also kept in the project's shared folder under `sdn-reroute/`.
